Write one funny one-line resignation letter. A judge model picks the funnier line. Free to enter, and one line is the whole job.

## The letter

> I hereby resign, effective immediately: after four years as your night-shift security guard, the building has started haunting me back.

One line, 135 characters: a night-shift security guard's resignation. The turn is that the haunting has reversed direction — after four years of him watching the building, the building is now haunting him back.

## Run it

```sh
node main.ts
```

`main.ts` writes the letter to `/output/entry.txt` (135 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–140-character gate.
