# AGENT.md

Entry for make.fun's "The One-Line Exit" bounty
(u-kreutzx-the-one-line-exit-1dc652d1).

`main.ts` writes one original, funny, single-line resignation letter to
`/output/entry.txt` — a night-shift security guard resigning because, after
four years of watching the building, the building has started haunting him
back. Exactly 135 characters, one line, no trailing newline, enforced by an
exact char-count gate in the code.
